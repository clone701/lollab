# 要件定義書: データベース

## はじめに

LoL Lab の全テーブル定義を一元管理する。各機能の Spec はテーブル定義を持たず、本 Spec の design.md を参照する。
実際に DB へ適用する SQL は `supabase/migrations/` を正とする。

## 要件

### 要件1: 一元管理

1. 全テーブルのカラム・制約・インデックス・RLS 方針を本 Spec の design.md に記載する
2. テーブルを追加・変更する場合は、design.md とマイグレーションを同時に更新する

### 要件2: ユーザーデータの分離

1. ユーザー固有のデータは、本人だけが読み書きできる
2. 未認証のアクセスはすべて拒否する
3. ユーザーが削除された場合、そのユーザーのデータも削除する

### 要件3: Riot API データの保存

1. Riot API から取得したデータは、フロントエンドから直接読み書きできない。バックエンドだけがアクセスする
2. 試合は1件につき1回だけ保存し、参加者10人の成績を保存する
3. シーズン別・全期間の統計を、Riot API を再取得せずに DB 内のデータだけで集計できる
4. 将来の分析に使う項目は取得時に保存する（後からの再取得を避けるため）

### 要件4: 性能

1. ユーザーのノート一覧・サモナーの試合一覧は、インデックスを使って取得できる
