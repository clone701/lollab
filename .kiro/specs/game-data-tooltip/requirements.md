# 要件定義: game-data-tooltip

## 概要

アイテム・ルーン・サモナースペル・スキルのアイコンにマウスを乗せると、名前と説明を出す。あわせて、ビルド画面と試合詳細のスキル表示を Q/W/E/R の文字からスキルの画像に変える。Issue #128。

## 前提

- データは Data Dragon 16.21.1（`D:\dev\16.21.1`）の日本語版を、加工せずにリポジトリへコピーする
- コピー先は元のフォルダ構成に合わせる（新しい版が出たら同じ場所へ上書きコピーする）
  - `D:\dev\16.21.1\data\…` → `frontend/public/images/data/…`
  - `D:\dev\16.21.1\img\…` → `frontend/public/images/img/…`
  - `D:\dev\img\<フォルダ>` → `frontend/public/images/<フォルダ>`（今回は無し）
- 今回コピーするもの: `data/ja_JP/item.json`・`runesReforged.json`・`summoner.json`・`champion/*.json`、`img/spell/*`・`img/passive/*`
- 既存の `public/images/champion` などは動かさない
- 対象はパソコンのみ（スマホのタップ操作は今回考えない）

## 範囲外

- 汎用ノートの新しい書き方（`/yasuo/Q`・`/item/3157`・`/rune/8112`）
- チャンピオンのアイコンのツールチップ
- スキルのランクごとの数値（例: ダメージ 25/70/115）。Data Dragon の `tooltip` は `{{ totaldamage }}` のような未解決の値を含むため、今回は `description`（概要）を使う。数値は #132 で CommunityDragon から計算して入れる（ツールチップの部品は今回のものを使い回す）
- スマホ・タッチ操作

## 要件

### 要件1: ツールチップの表示

**ユーザーストーリー:** ビルドを見ているプレイヤーとして、アイコンが何かをその場で知りたい。

1. マウスをアイコンに乗せたとき、またはキーボードでアイコンにフォーカスしたとき、ツールチップを表示する
2. マウスが離れたとき、フォーカスが外れたとき、Esc キーを押したとき、ツールチップを閉じる
3. ツールチップは画面の外にはみ出さない位置に出す
4. ツールチップの内容はスクリーンリーダーでも読める（アイコンと説明を関連付ける）
5. 説明データの読み込み中は名前だけを出し、読み込みに失敗したときは名前だけを出す（画面は壊さない）
6. 説明データは初めて必要になったときに読み込み、同じページでは再読み込みしない

### 要件2: アイテムのツールチップ

1. アイテム名、合計価格（ゴールド）、説明を表示する
2. 説明のステータス（例: 魔力 105）と効果の見出し（例: 時間停止）を、本文と区別して表示する
3. Data Dragon に無いアイテム ID のときは、ツールチップに「情報がありません」と出す

### 要件3: ルーンのツールチップ

1. ルーン名と説明（`longDesc`）を表示する
2. ルーンのパス（例: 栄華）のアイコンには、パスの名前だけを表示する

### 要件4: サモナースペルのツールチップ

1. スペル名、クールダウン（秒）、説明を表示する

### 要件5: スキルの画像とツールチップ

1. ビルド画面のスキル（優先順・スキル順の表）と、試合詳細のスキルの上げ順で、Q/W/E/R の文字の代わりにそのチャンピオンのスキル画像を表示し、画像の隅に Q/W/E/R の文字を重ねる
2. スキル画像が読み込めないときは、今と同じ Q/W/E/R の文字を表示する
3. スキルのツールチップに、キー（Q/W/E/R）、スキル名、クールダウン（例: 10/9.5/9/8.5/8 秒）、コスト（例: 70 マナ）、説明を表示する
4. コストが無いスキル（`costBurn` が `0`）はコストを表示しない
5. パッシブのアイコンをビルド画面のスキル欄に表示し、名前と説明のツールチップを出す

### 要件6: ツールチップを付ける場所

| 画面 | アイテム | ルーン | スペル | スキル |
|---|---|---|---|---|
| ビルド画面（`/champion/[championName]`） | ○ | ○ | ○ | ○ |
| 試合詳細（概要・ビルド） | ○ | ○ | ○ | ○（ビルドタブ） |
| 試合カード | ○ | ○ | ○ | － |
| 対策ノートの閲覧モード（作成・編集は対象外） | ○（初期アイテム） | ○（パス・ルーン・シャード） | ○ | － |

### 要件7: 説明文の安全な表示

1. 説明文の HTML 風のタグ（`<br>`・`<stats>`・`<active>` など）は、決めたタグだけを React の要素に変換し、それ以外のタグは文字として表示せずに取り除く
2. `dangerouslySetInnerHTML` は使わない

### 要件8: 性能

1. アイテムの説明データの通信量は圧縮後 150KB 以下（CloudFront の圧縮を使う。16.21.1 で約 117KB）
2. スキルのデータはチャンピオン1体分のファイルだけを読み込む（圧縮後 1体 約 4KB）
3. 説明データの読み込みで、ページの最初の表示を遅らせない
