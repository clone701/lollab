# 要件定義書: マイピック

## はじめに

ノート画面に「マイピック」タブを追加する。レーンごとに、相手チャンピオンそれぞれに対して自分が出すチャンピオンの候補を表にまとめ、試合前のピックの判断に使う。
表から自分のピックを押すと、その組み合わせの対策ノートを開けるようにし、ピックの判断と対策の確認をつなげる。

## 用語集

- **マイピック表**: 1つのレーンについて、相手チャンピオンごとに自分のピックの候補を並べた表。名前を付けて何枚でも作れる
- **レーン**: TOP / JUNGLE / MID / BOT / SUPPORT
- **相手チャンピオン**: 表の行。全チャンピオンが対象
- **ピック**: ある相手チャンピオンに対して自分が出すチャンピオン。1つの相手に対して順番付きで複数持てる
- **対策ノート**: 既存の「自分のチャンピオン vs 相手チャンピオン」のノート

---

## 要件

### 要件1: タブ

**ユーザーストーリー:** プレイヤーとして、ピックの表を対策ノートや汎用ノートと同じ画面で管理したい。そうすることで、ノートを行き来しやすくなる。

#### 受け入れ基準

1. ノート画面は「対策ノート」「汎用ノート」「マイピック」のタブを持つ
2. マイピックタブはログインしたユーザーの表だけを表示する

### 要件2: 表の一覧と作成

**ユーザーストーリー:** プレイヤーとして、用途ごとにピックの表を分けたい。そうすることで、レーンや目的に合わせて使い分けられる。

#### 受け入れ基準

1. マイピックタブは、作成した表の一覧を表の名前・レーン・入力済みの相手の数・更新日時とともに表示する
2. 一覧はレーンで絞り込める
3. WHEN ユーザーが新規作成を押した場合、システムは表の名前とレーンを入力させてから表を作る
4. 表の数に上限は設けない
5. 表の名前は1〜50文字とする
6. IF 表が1つもない場合、システムは「マイピック表がありません」と新規作成のボタンを表示する

### 要件3: 表の編集

**ユーザーストーリー:** プレイヤーとして、相手チャンピオンごとに自分のピックの候補を登録したい。そうすることで、試合前に誰を出すかすぐに判断できる。

#### 受け入れ基準

1. 編集画面は全チャンピオンを相手チャンピオンの行として並べる
2. 各行には自分のピックの枠を初期で3つ表示し、枠ごとにチャンピオンを選べる
3. WHEN ユーザーが行の「＋」を押した場合、システムはその行のピックの枠を1つ増やす。枠は1行につき最大10とし、10に達したら「＋」を押せなくする
4. ユーザーはピックを枠から外せる。ピックの順番は左から並んだ順とする
5. 同じ行に同じチャンピオンを2回選べない
6. 相手チャンピオンの行は名前（日本語名・読み・英語名）で検索できる
7. 「入力済みの行だけ表示」に切り替えられる
8. 表の名前とレーンは編集画面で変えられる
9. WHEN ユーザーが保存を押した場合、システムは表を保存し、閲覧画面に移る
10. WHILE 保存されていない変更がある間、システムは画面を離れる前に確認する

### 要件4: 表の閲覧

**ユーザーストーリー:** プレイヤーとして、試合前に相手チャンピオンを探して、自分のピックとその対策を素早く確認したい。

#### 受け入れ基準

1. 閲覧画面は、ピックが1つ以上ある相手チャンピオンの行だけを、相手チャンピオンのアイコン・名前と、自分のピックのアイコン（順番どおり）で表示する
2. 閲覧画面は相手チャンピオンを名前で検索できる
3. WHEN ユーザーが自分のピックのアイコンを押した場合、システムは「そのピック vs 相手チャンピオン」の対策ノートの画面を開く
4. IF その組み合わせの対策ノートがない場合、システムは既存の対策ノートと同じ「ノートがありません」の画面を表示する
5. 閲覧画面から編集・削除ができる。削除は確認してから行う

### 要件5: データ

#### 受け入れ基準

1. 表とピックはユーザーごとに保存し、本人だけが読み書きできる
2. 保存したピックの順番を保つ
3. 表を削除すると、その表のピックも削除される

### 要件6: 範囲外

- 汎用ノート「TOP PICK」からの自動の移行（ユーザーが手で入れ直す）
- 表の共有・公開
- ピックの勝率など統計の表示
